# Nuur Atmospheric Backgrounds — Image Generation Brief

## Goal

Produce **6 photo-realistic atmospheric backgrounds** that feel like one family. Each is mood-mapped to a content category. Cards overlay content on these — so the images must have strong negative space in the upper two-thirds and silhouetted detail concentrated at the bottom edges.

## Shared Visual DNA (applies to all 6)

Every image must share these qualities so the library feels cohesive:

- **Cinematic photography**, medium format look — *not* illustration, *not* cartoon, *not* painting
- **Moody, dark overall** — deep shadows dominate, one concentrated light source per image
- **Empty upper ~60%** of the frame (this is where Arabic + translation will sit)
- **Silhouetted detail in lower ~40%** — architecture, foliage, or horizon
- **Atmospheric haze / subtle mist** — softens edges, adds depth
- **Film grain texture** — prevents that flat “AI render” feel
- **No text. No calligraphy. No Arabic lettering. No logos. No people. No faces.**
- **No prominent religious symbols** (no explicit crescent-stars, no mihrabs with text, no obvious Quran pages)
- **Aspect ratio 2:3** (for share card at 4:5 we crop; for wallpaper at 9:19.5 we extend — generate tall)
- **Minimum resolution: 2160×3240** (retina 2× for 1080×1620 display)

## Negative Prompt (paste on every image)

`text, calligraphy, arabic script, letters, watermark, logo, signature, people, faces, humans, cartoon, illustration, anime, painterly, oversaturated, kitsch, clipart, sticker`

## Achieving Consistency Across the Set

The biggest failure mode is the 6 images looking like they came from 6 different photographers. Three techniques to prevent this:

### Technique 1: Style reference (Midjourney)

Generate the first image you’re happy with. Copy its URL. Append `--sref <url>` to the other 5 prompts. This locks the aesthetic.

### Technique 2: Seed locking (any tool)

If your tool supports seeds, use the same seed across all 6 generations after finding one that works.

### Technique 3: Style suffix

Append the same style phrase to every prompt:

> `...shot on Hasselblad 500C, Kodak Portra 400, dreamy cinematic tone, subtle halation, consistent warm shadows, editorial photography`

## Post-Processing Checklist

Before bundling each image:

1. **Darken the upper portion** an extra 10-15% if text legibility might be an issue (Photoshop curves or free alternative: Photopea)
1. **Verify dominant negative space** is in the upper 60% — if the image is too busy up top, the Arabic won’t read
1. **Export as WebP at quality 80-85** (better size/quality ratio than JPG for photos)
1. **Target file size: 180-280 KB per image** — the whole background library should stay under 1.5 MB bundled
1. **Rename exactly to the filenames above** — `dawn-minaret.webp`, etc. — the code references these
